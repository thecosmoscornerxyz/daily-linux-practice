# Daily Agent Prompt Engineering

## 1. ROLE
Who is the agent? What is its responsibility?

## 2. GOAL
What must it accomplish? What defines success?

## 3. CONTEXT
What environment and facts does it need?

## 4. CONSTRAINTS
What can and cannot the agent do?

## 5. RESOURCES
What tools, APIs, or databases can it use?
When should each resource be used?

## 6. OUTPUT
What response format is required?

## 7. FEEDBACK
What happens if information is missing?
What happens when a tool fails?
